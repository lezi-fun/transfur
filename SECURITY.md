# Security policy

FurryFly builds in this repository are beta software. Use disposable wallets on
an isolated test network while evaluating them. CI artifacts are not covered by
Bob Wallet's release signing keys.

For a security issue specific to this fork, contact this repository's maintainer
privately (use **Security → Report a vulnerability** if GitHub offers it). Do not
post sensitive details in a public issue. Never share wallet seeds, private keys,
passwords, or API keys in a report.

For a problem confirmed in the unmodified upstream product, see the upstream
[Bob Wallet security policy](https://github.com/shadstoneofficial/bob-wallet/security/policy).
